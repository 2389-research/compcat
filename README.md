## what is this

A Claude Code skill that intercepts `/compcat` — the inevitable typo of `/compact` — shows you a COMPuter CAT, and points you at the real command. The cat has opinions. The cat is also slightly judgmental. The cat is correct.

## install

```bash
/plugin marketplace add 2389-research/claude-plugins
/plugin install compcat@2389-research
```

Then, the next time your fingers betray you, `/compcat` will summon the cat instead of failing silently.

## what it does

1. You type `/compcat` (because of course you did).
2. Cat appears at a tiny CRT running `/compact`.
3. Cat says something cat-flavored about your typo.
4. You type `/compact` like you meant to. Context is compacted. Cat resumes loafing.

## why

`/compact` and `/compcat` differ by exactly which side of the `a` the `c` lives on. Human fingers are unreliable. The cat is here to absorb the shame.
